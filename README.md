# Snake Game 🐍

## What's This? 🤔

A simple Snake Game made using pygame. Move the snake, eat the food, and grow bigger—just don’t crash into yourself or the walls! 😄

## Features ✨

✅ Score Counter - Keeps track of your points!
✅ Game Over Screen - Shows your final score when you crash.
✅ Restart Option - Press 'R' to start fresh.
✅ Quit Option - Press 'Q' if you wanna exit.
✅ Smooth Controls - No lag, just smooth movement!

## Prerequisites 🛠️

Make sure you have Python installed. You also need pygame. Install it with:

pip install pygame

## How to Run 🚀

Download snake_game.py

Open a terminal in that folder.

Run the game with:

python snake_game.py

## Controls 🎮

🔼 Up Arrow - Move Up🔽 Down Arrow - Move Down◀️ Left Arrow - Move Left▶️ Right Arrow - Move Right🔄 
'R' - Restart after game over❌ 
'Q' - Quit the game

## How to Play 🏆

Move the snake around using arrow keys.

Eat the red food blocks to grow bigger.

Avoid crashing into the walls or yourself.

The longer you survive, the higher your score!
